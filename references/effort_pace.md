# 等强配速（Effort Pace）计算规则

> 基于坡度数据将山地/坡路配速折算为等效平路配速，>10m 爬升时自动计算。爬升 <10m 时等强配速 = 实际配速。

---

## 方案 A — 逐公里分段法（首选，有计圈数据时）

对每个计圈（≈每公里）独立折算，再按距离加权平均。

### 上坡折算

```
等效配速(s) = 实际配速(s) / 1.05^坡度%
```

- 坡度% = (elevationGain - elevationLoss) / 1000 × 100
- 指数 1.05 为通用坡度因子（接近 Daniels VDOT 坡度调整系数）
- 坡度越大，等效配速越慢；5% 坡度 ≈ 配速÷1.276 ≈ 折损约 22%

### 下坡折算

```
等效配速(s) = 实际配速(s) × (1 + 0.3 × |坡度%| / 10)
```

- 下坡效率有限，不能像上坡一样线性放大
- 系数 0.3 为经验值：5% 下坡 → 配速×1.15，折损约 15%

### 心率个性化修正

当该公里平均心率显著偏离训练平均心率时，按比例微调：

| 条件 | 修正 |
|:---|:---|
| 某公里心率 > 平均心率 × 1.05 | 实际付出更多努力 → 等效配速再降 30% × (心率比 - 1) |
| 某公里心率 < 平均心率 × 0.95 | 该公里较轻松 → 等效配速稍升 20% × (1 - 心率比) |

### 下限保护

```
等效配速 ≥ 实际配速 × 0.7（防止极端坡度下折算溢出）
```

---

## 方案 B — 整体坡度法（兜底，无计圈数据时）

```
平均坡度% = 总爬升(m) / (总距离(m) × 0.01)
等强配速(s) = 平均配速(s) / 1.05^平均坡度%
```

---

## 方案 C — Naismith 参考法（另存参考）

```
等效平路距离 = 实际距离(km) + 总爬升(m) / 100
Naismith 配速 = 总时间 / 等效平路距离
```

每爬升 100m 等效多跑 1km 平路，登山/越野跑常用经验规则。

## 数据来源

| 字段 | API 来源 |
|:---|:---|
| 每公里净爬升 | `splits.lapDTOs[i].elevationGain` / `.elevationLoss` |
| 每公里配速 | `splits.lapDTOs[i].duration` / `.distance` |
| 每公里心率 | `splits.lapDTOs[i].averageHR` |
| 总爬升 | `activity.summaryDTO.elevationGain` |

Garmin 计圈数据通过 `client.connectapi('/activity-service/activity/{id}/splits')` 获取，详参 `api_reference.md`。
