# 天气与不适指数（DI）分析参考

> 训练分析时，用于量化天气对表现的影响。

---

## 一、数据来源与优先级

**每次分析关键训练（节奏跑/长距离/间歇）时，必须采集训练当天的天气数据。**

### 数据获取优先级

1. **Garmin API（首选）**：`get_activity_weather(activityId)` 直接返回活动关联的气象站数据
   - 返回字段：温度(°F)、相对湿度、天气状况描述、风速风向
   - 覆盖大部分含 GPS 轨迹的活动（约 90%+）
2. **Open-Meteo Archive API（兜底）**：仅当 Garmin API 未返回温度数据时启用
   - 从活动起点的经纬度查询
   - 免费、无需 API Key

### Open-Meteo 兜底查询示例

```
https://archive-api.open-meteo.com/v1/archive?
  latitude={lat}&longitude={lon}&
  start_date={YYYY-MM-DD}&end_date={YYYY-MM-DD}&
  hourly=temperature_2m,relative_humidity_2m,precipitation,weather_code&
  timezone=Asia/Shanghai
```

## 二、不适指数（Discomfort Index）公式

```
DI = T - 0.55 × (1 - 0.01 × H) × (T - 14.5)
其中 T = 温度(°C), H = 相对湿度(%)
```

---

## 三、DI 参考阈值

| DI 范围 | 影响级别 | 典型表现 |
|---------|---------|---------|
| **< 17** | ✅ 最佳区 | 15-17°C + 60-80%RH → 正常发挥，可冲刺 Best |
| **17 - 19** | ⚠️ 轻度影响 | 配速惩罚约 +5~10s/km |
| **> 19** | 🔴 明显影响 | 配速惩罚可感知，但训练意志可部分抵消 |
| **≥ 21** | 🔴🔴 显著影响 | 即使短距离也会明显感知 |

---

## 四、温度量化影响（粗估公式）

```
基准温度: 17°C（晨间低温基准线）
  ≤18°C: 基准表现区
  20°C:  配速惩罚 +5s/km vs 17°C
  22°C:  配速惩罚 +10s/km vs 17°C（训练意图强时可忽略此惩罚）
```

---

## 五、湿度量化影响（粗估公式）

```
同温下每+10%RH ≈ +3-5s/km 配速惩罚
湿度 60-70% ≈ 最舒适
湿度 80-95% ≈ 可感知但非致命
```

## 六、关键分析原则：疲劳 > 天气

### 分析优先级

**查天气前，先查前 3 天跑量和睡眠质量。**

1. **前 3 天累计跑量**：近期是否有连续大跑量/双跑日？
2. **前夜睡眠**：是否 ≤ 6h 或睡眠评分 ≤ 70？
3. **训练意图**：是否是计划中的关键课（MP/间歇）？
4. **温湿度**：最后考虑天气因素

### 典型例子

| 对比 | 前一天休息 | 前3天连续30km+ |
|:----|:---------:|:-------------:|
| 训练结果 | 配速达标，质量高 | 配速断崖下降 |
| 主因 | 恢复充分 | 累积疲劳 |
| 天气解释力 | <10% | <10% |

### 结论

- 纯温湿度解释力 < 10%
- 疲劳累积解释力 > 80%
- **不要将单次表现差异全部归因于天气**
