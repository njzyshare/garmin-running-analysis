## 一、中国区登录（Garmin.cn）Monkey-Patch 实现

### 问题背景

Garmin 中国区（garmin.cn）与国际区（garmin.com）的认证流程不同：
- 国际区使用 `connect.garmin.com`
- 中国区使用 `connect.garmin.cn`，DI token 端点为 `diauth.garmin.cn`

### Monkey-Patch 代码

`scripts/garmin_auth.py` 中根据 `region` 配置自动应用以下 patch：

```python
# 仅在中国区生效
if region == "cn":
    # Patch 1: JWT_WEB 错误不终止策略链
    # 将 JWT_WEB 失败从 AuthenticationError 转为可继续的 ConnectionError
    def _patched_init(self, *args, **kwargs):
        original_init(self, *args, **kwargs)
        self._auth_properties["JWT_WEB"] = {
            "url": "https://connect.garmin.cn/api/auth/jwt",
            "redirect": "https://connect.garmin.cn",
        }

    # Patch 2: CN DI token 端点
    # 先尝试 diauth.garmin.cn 交换 DI token
    original_exchange = client.exchange_token
    def _patched_exchange(self, client_id, token):
        try:
            return original_exchange(client_id, token)
        except GarminConnectConnectionError:
            # Fallback to CN endpoint
            return self._exchange_cn_token(client_id, token)

    # Patch 3: token 保存修复
    # 使用 client.client.dump() 而非不存在的 client.garth.dump()
    original_dump = client.client.dump
    def _patched_dump(self):
        return original_dump()
```

### Token 存储

- 存储路径：`~/.clawdbot/garmin/garmin_tokens.json`
- 不同区域的 token 不互通，切换区域后需重新登录

## 二、PB 提取函数实现

### extract_pb_from_activities()

从历史活动记录按距离区间提取个人最佳成绩：

```python
def extract_pb_from_activities(activities):
    """
    从活动记录提取 PB，支持距离区间和活动名关键词匹配

    距离区间定义：
    - 5K: [4.5, 5.5] km
    - 10K: [9.0, 11.0] km
    - 半马: [20.0, 22.0] km
    - 全马: [40.0, 45.0] km

    关键词匹配（用于识别比赛）：
    - 半马: ["半马", "21km", "21.1", "half", "hm"]
    - 全马: ["全马", "42km", "42.2", "full", "fm", "marathon"]
    """
    pb_by_distance = {
        "5k": {"distance": None, "time": float('inf')},
        "10k": {"distance": None, "time": float('inf')},
        "half_marathon": {"distance": None, "time": float('inf')},
        "marathon": {"distance": None, "time": float('inf')},
    }

    for activity in activities:
        distance_km = activity["distance"] / 1000
        duration_sec = activity["duration"]

        # 5K
        if 4.5 <= distance_km <= 5.5 and duration_sec < pb_by_distance["5k"]["time"]:
            pb_by_distance["5k"] = {"distance": distance_km, "time": duration_sec}

        # 10K
        elif 9.0 <= distance_km <= 11.0 and duration_sec < pb_by_distance["10k"]["time"]:
            pb_by_distance["10k"] = {"distance": distance_km, "time": duration_sec}

        # 半马
        elif 20.0 <= distance_km <= 22.0:
            name = activity.get("activityName", "").lower()
            if any(kw in name for kw in ["半马", "21km", "half", "hm"]):
                if duration_sec < pb_by_distance["half_marathon"]["time"]:
                    pb_by_distance["half_marathon"] = {"distance": distance_km, "time": duration_sec}

        # 全马
        elif 40.0 <= distance_km <= 45.0:
            name = activity.get("activityName", "").lower()
            if any(kw in name for kw in ["全马", "42km", "full", "fm", "marathon"]):
                if duration_sec < pb_by_distance["marathon"]["time"]:
                    pb_by_distance["marathon"] = {"distance": distance_km, "time": duration_sec}

    return pb_by_distance
```

### PB 合并展示逻辑

```python
def merge_personal_records(api_pb, activity_pb):
    """
    合并 Garmin API PB 和活动记录 PB

    优先级：
    1. Garmin API PB（最权威）
    2. 活动记录 PB（补充缺失项）
    """
    merged = {}

    # API PB 优先
    for key, value in api_pb.items():
        if value and value != "--":
            merged[key] = {"value": value, "source": "Garmin API"}

    # 活动 PB 补充
    for key, value in activity_pb.items():
        if key not in merged and value["time"] != float('inf'):
            merged[key] = {"value": value["time"], "source": "活动记录"}

    return merged
```

## 三、睡眠日期关联实现

### _sleep_for_training()

训练日 D 的睡眠 = Garmin 记录中 D+1 日期的睡眠（D 晚入睡 D+1 晨醒来）

```python
def _sleep_for_training(training_date, daily_sleep_data):
    """
    获取训练日对应的睡眠数据

    Args:
        training_date: 训练日期 (datetime.date)
        daily_sleep_data: Garmin 返回的每日睡眠数据字典，key 为日期字符串

    Returns:
        training_date 晚入睡对应的睡眠数据
    """
    # Garmin 用醒来日期记录，所以训练日 D 的睡眠在 D+1
    next_day = training_date + datetime.timedelta(days=1)
    next_day_str = next_day.strftime("%Y-%m-%d")

    return daily_sleep_data.get(next_day_str, None)
```

### 使用示例

```python
from datetime import date, timedelta

# 假设 18 号进行了训练
training_date = date(2026, 5, 18)

# 获取 18-19 号的睡眠数据（Garmin 记录为 19 号）
sleep_data = _sleep_for_training(training_date, daily_sleep_data)
# sleep_data["dailySleepDTO"]["sleepTimeSeconds"] = 28800 (8小时)
```

## 四、计圈数据启发式分析

### analyze_splits_heuristic()

`scripts/garmin_report.py` 中的启发式分析函数，依次执行 3 种检测：

```python
def analyze_splits_heuristic(laps):
    """
    分析计圈数据，识别最佳呈现方式

    Returns:
        dict: {
            "type": "suspect" | "auto_lap_1km" | "interval" | "native",
            "laps": [...],
            "description": str
        }
    """
    # 提取有效圈（排除热身/冷却圈）
    valid_laps = [lap for lap in laps if lap.get("distance", 0) > 100]  # > 100m

    if not valid_laps:
        return {"type": "suspect", "description": "无有效计圈数据"}

    total_distance = sum(lap.get("distance", 0) for lap in valid_laps)
    lap_distances = [lap.get("distance", 0) / 1000 for lap in valid_laps]  # km

    # ===== Heuristic 1: 异常大圈 (suspect) =====
    # 某一圈距离 > 总距离的 50%，说明 GPS 粒度过粗
    for i, dist in enumerate(lap_distances):
        if dist > total_distance * 0.5:
            return {
                "type": "suspect",
                "description": f"第{i+1}圈占总距离 {dist/total_distance*100:.1f}%，GPS 粒度过粗"
            }

    # ===== Heuristic 2: 自动公里计圈 (auto_lap_1km) =====
    # ≥60% 的圈在 0.95-1.05km 范围内
    km_laps = sum(1 for d in lap_distances if 0.95 <= d <= 1.05)
    if km_laps / len(lap_distances) >= 0.6:
        return {
            "type": "auto_lap_1km",
            "description": "Garmin 自动每公里计圈",
            "laps": valid_laps
        }

    # ===== Heuristic 3: 配速交替间歇 (pace-based interval) =====
    paces = []
    for lap in valid_laps:
        dist_km = lap.get("distance", 0) / 1000
        duration_sec = lap.get("duration", 0)
        if dist_km > 0 and duration_sec > 0:
            pace = duration_sec / dist_km  # 秒/km
            paces.append({
                "pace": pace,
                "distance": dist_km,
                "hr": lap.get("averageHR", 0),
                "lap_index": valid_laps.index(lap)
            })

    if len(paces) >= 6:
        median_pace = sorted(p["pace"] for p in paces)[len(paces) // 2]

        # fast: ≤ median × 0.88 (比中位快 ≥12%)
        # slow: ≥ median × 1.08 (比中位慢 ≥8%)
        classifications = []
        for p in paces:
            ratio = p["pace"] / median_pace
            if ratio <= 0.88:
                classifications.append("fast")
            elif ratio >= 1.08:
                classifications.append("slow")
            else:
                classifications.append("medium")

        # 统计 fast↔slow 交替次数
        transitions = sum(
            1 for i in range(1, len(classifications))
            if classifications[i] != classifications[i-1]
            and "fast" in [classifications[i], classifications[i-1]]
        )

        fast_count = classifications.count("fast")
        slow_count = classifications.count("slow")

        if transitions >= 3 and fast_count >= 3 and slow_count >= 3:
            return {
                "type": "interval",
                "description": f"检测到 {fast_count} 个快段 + {slow_count} 个慢段，{transitions} 次交替",
                "classifications": classifications,
                "median_pace": median_pace
            }

    # ===== 兜底: native =====
    return {
        "type": "native",
        "description": "手表原生计圈",
        "laps": valid_laps
    }
```

## 五、天气数据获取

### Open-Meteo Archive API

```python
import requests

def get_weather_history(lat, lon, date_str):
    """
    从 Open-Meteo 获取历史天气数据

    Args:
        lat: 纬度
        lon: 经度
        date_str: 日期 (YYYY-MM-DD)

    Returns:
        dict: {"temperature": float, "humidity": int, "weather": str}
    """
    url = "https://archive-api.open-meteo.com/v1/archive"
    params = {
        "latitude": lat,
        "longitude": lon,
        "start_date": date_str,
        "end_date": date_str,
        "hourly": "temperature_2m,relative_humidity_2m,weather_code",
        "timezone": "Asia/Shanghai"
    }

    response = requests.get(url, params=params)
    data = response.json()

    # 取上午训练时段（5-9am）的平均值
    hourly = data["hourly"]
    temps = hourly["temperature_2m"][5:10]  # 5-9点
    humids = hourly["relative_humidity_2m"][5:10]
    weather_code = hourly["weather_code"][5]  # 取中间时段

    return {
        "temperature": sum(temps) / len(temps),
        "humidity": sum(humids) / len(humids),
        "weather": wmo_code_to_chinese(weather_code)
    }
```

### DI 不适指数计算

```python
def calculate_di(temperature_c, humidity_percent):
    """
    计算不适指数 (Discomfort Index)

    DI = T - 0.55 × (1 - 0.01 × H) × (T - 14.5)

    Args:
        temperature_c: 温度 (°C)
        humidity_percent: 相对湿度 (%)

    Returns:
        float: DI 值，越低越舒适
    """
    T = temperature_c
    H = humidity_percent
    DI = T - 0.55 * (1 - 0.01 * H) * (T - 14.5)
    return round(DI, 1)

# DI 区间判断
def get_di_level(di):
    if di < 17:
        return "最佳区", "green"
    elif di < 19:
        return "轻度影响", "yellow"
    elif di < 21:
        return "明显影响", "orange"
    else:
        return "高度影响", "red"

# 配速惩罚估算
def estimate_pace_penalty(di, base_di=16.5):
    """
    估算 DI 导致的配速惩罚

    经验公式（基于福州夏季晨跑数据）：
    - DI 每增加 1，配速惩罚约 +5s/km
    """
    diff = di - base_di
    if diff <= 0:
        return 0
    return round(diff * 5)  # 秒/km
```

```python
def get_race_time(race_preds, distance_key):
    """获取比赛预测时间"""
    # 驼峰格式
    camel_key = f"time{distance_key.upper()}" if distance_key != "5k" else "time5K"
    if camel_key in race_preds:
        return race_preds[camel_key]

    # 旧格式 fallback
    old_keys = {"5k": "5k", "10k": "10k", "half": "hm", "full": "fm"}
    old_key = old_keys.get(distance_key)
    if old_key and old_key in race_preds:
        return race_preds[old_key]

    return None
```

## 九、错误处理

### 常见错误及解决方案

| 错误 | 原因 | 解决方案 |
|------|------|---------|
| `GarminConnectAuthenticationError` | 凭据无效 | 检查邮箱/密码，尝试网页登录验证 |
| `GarminConnectConnectionError` | 网络问题/频率限制 | 等待几分钟后重试，检查网络 |
| 返回 `None` | 设备未佩戴/不支持该指标 | 确认当天有佩戴设备 |
| Token 过期 | 会话超时 | `python3 scripts/garmin_auth.py login` 重新认证 |

### 重试策略

```python
import time
from garminconnect import GarminConnectConnectionError

def fetch_with_retry(func, max_retries=3, delay=5):
    """带重试的数据获取函数"""
    for attempt in range(max_retries):
        try:
            return func()
        except GarminConnectConnectionError as e:
            if attempt < max_retries - 1:
                print(f"连接失败，{delay}秒后重试 ({attempt+1}/{max_retries})")
                time.sleep(delay)
            else:
                raise e
```
